# DevSorteio

Sorteador eletrônico de números desenvolvido para praticar conceitos de JavaScript, principalmente o uso de `Math.random()`.

## Sobre o projeto

O DevSorteio permite escolher um número mínimo e um número máximo e gerar um número aleatório dentro desse intervalo.

## Funcionalidades

- Definir número mínimo
- Definir número máximo
- Sortear um número aleatório
- Exibir o número sorteado
- Sortear novamente
- Validação do intervalo informado

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Conceitos praticados

- `document.querySelector()`
- `addEventListener()`
- Funções
- `const`
- `Number()`
- `Math.random()`
- `Math.floor()`
- Manipulação do DOM
- `classList.add()`
- `classList.remove()`
- `setTimeout()`

## Objetivo

Praticar conceitos de JavaScript por meio da criação de um sorteador funcional e responsivo.
